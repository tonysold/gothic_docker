# Gothic Catalogue (Pet Project)

Информационная система по вселенной игры Gothic (2001).
Проект реализован на чистом PHP (Native PHP) без использования фреймворков.
Позволяет просматривать данные о персонажах, оружии и лагерях, а также включает систему регистрации и авторизации.

## 🛠 Технологический стек
*   **Backend:** PHP 8.3 (Native)
*   **Database:** MariaDB / MySQL
*   **Frontend:** HTML5, CSS3 (Modern Dark Theme)
*   **Environment:** Docker, Nginx, Composer (PSR-4 Autoload)

---

## 🚀 Запуск через Docker (Рекомендуемый способ)
Это самый простой способ. Все окружение (PHP, база данных, веб-сервер) настроено автоматически.

**Требования:** Установленный Docker и Docker Compose.

1.  Клонируйте репозиторий.
2.  Перейдите в папку с Docker-конфигурацией:
    ```bash
    cd .docker
    ```
3.  Запустите сборку и контейнеры:
    ```bash
    docker-compose up -d --build
    ```
4.  Откройте проект в браузере: [http://localhost:8081](http://localhost:8081)

*База данных будет инициализирована автоматически при первом запуске из файла `.docker/data/gothic.sql`.*

---

## 🔧 Запуск без Docker (Локальная среда)
Если вы хотите запустить проект на локальном сервере (например, OpenServer, XAMPP или нативном PHP).

**Требования:** PHP 8.1+, MySQL/MariaDB, Composer.

1.  **Настройка базы данных:**
    *   Создайте базу данных с названием `gothic`.
    *   Импортируйте дамп базы из файла `.docker/data/gothic.sql`.
    *   Проверьте настройки подключения в `App/Classes/DatabaseConnection.php` (параметры `DB_SERVER`, `DB_USER`, `DB_PASS`).

2.  **Установка зависимостей:**
    ```bash
    composer install
    ```

3.  **Запуск веб-сервера:**
    Настройте ваш веб-сервер так, чтобы корневой директорией была папка `public/`.
    Либо запустите встроенный сервер PHP из корня проекта:
    ```bash
    php -S localhost:8000 -t public/
    ```

4.  **Доступ:** [http://localhost:8000](http://localhost:8000)

## 📂 Структура проекта
*   `App/` — основная логика (Classes, Models, Views).
*   `public/` — точка входа (`index.php`), стили и изображения.
*   `.docker/` — конфигурация Docker (Dockerfile, Nginx, SQL дамп).
*   `vendor/` — автозагрузка классов (генерируется Composer).
